## 📌 About The Project

**Question Paper Maker** is a lightweight and efficient web application designed to simplify the process of creating structured question papers.

It allows users to dynamically add questions, preview them in real-time, and generate a clean formatted paper — all within seconds.

Built using **pure frontend technologies**, this project ensures **high performance**, **zero dependencies**, and **maximum simplicity**.
